# Once Human Survival Toolkit — feature reference

A survival toolkit workspace for Once Human, built around character notes and resource groups, with session planning kept in a separate reference area.

| Section | Description |
|---|---|
| Character notes | Character-related parameters and the settings associated with the selected category. |
| Resource groups | Inventory and resource categories organized alongside their related values and notes. |
| Session planning | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
